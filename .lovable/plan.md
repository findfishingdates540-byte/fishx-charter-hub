# Unify operator settings

## Changes
- Keep one **Settings** destination in every operator navigation and remove the duplicate Account/Settings shortcuts from the shared operator menu.
- Add **My Account** as the first section inside the shared operator Settings screen, so captains, guides, marinas, shops, and other operators get the same order.
- Open Settings on **My Account** by default while preserving existing bookmarkable links to business profile, visibility, team, notifications, payouts, and vertical-specific sections.
- Apply the operator dark navy/cyan styling to the My Account content and the surrounding settings experience across phone, tablet, and desktop.
